## 3. 预期时间模型

### 无尽深渊 (super)
```
解路径 ≈ 3500 格
效率 ≈ 40%
步数 = 3500 / 0.4 ≈ 8750 步
移动时间 = 8750 × 0.13s = 1138 秒
思考/停顿 ≈ 10% → 总时间 ≈ 1250 秒 ✅
```

### 无尽深渊MAX (supermax)
```
解路径 ≈ 5500 格
效率 ≈ 30%（极限死路导致大量折返）
步数 = 5500 / 0.3 ≈ 18333 步
移动时间 = 18333 × 0.13s = 2383 秒
思考/停顿 ≈ 5% → 不计（高手专注）
快速模式 70ms → 18333 × 0.07s = 1283 秒
中速模式 130ms → 2383 秒 → 约 2000 秒（中速玩家使用火炬/黑灯模式）
```

## 5. 渲染性能考量

supermax 的 100×100 网格产生 201×201 墙面网格：
- Canvas 单元尺寸 `cs = Math.floor(600/201) = 2`，但最小为 3
- 实际画布 = `201 × 3 = 603px`，容器裁剪边缘 1.5px，可忽略
- 渲染循环：`201 × 201 = 40401` 次迭代，Canvas 2D 可轻松处理
- 迷雾系统：每帧更新 10000+ 个可见格，性能可接受
