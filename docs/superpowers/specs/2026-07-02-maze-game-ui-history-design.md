# 迷宫游戏 — 闯关反馈、历史记录与 UI 重构设计

日期：2026-07-02 | 状态：起草

## 1. 闯关完成报告

### 1.1 触发时机

闯关模式通关最后一个关卡后，在已有通关弹窗基础上追加**详细报告面板**，以折叠/展开形式呈现。

### 1.2 报告内容

#### 1.2.1 顶部概览（通关弹窗已有）

- 总用时 / 总步数 / 总分
- 星级评价（1~3 星，基于综合表现）

#### 1.2.2 逐关详情表（新增）

| 关卡 | 难度 | 用时 | 步数 | 效率 | 得分 |
|------|------|------|------|------|------|
| #1 | 极简入门 | 00:12 | 45 | 88% | 1520 |
| #2 | 休闲普通 | 00:35 | 102 | 76% | 2340 |

- 每行用迷你进度条可视化效率
- 最优单关（最快用时/最少步数）高亮

#### 1.2.3 生涯统计（新增）

- 本次闯关总得分
- 平均效率
- 死路探入次数（总 backtrack 次数）

### 1.3 技术方案

- 在 App 类新增 `_campaignStats` 数组，在 `_loadCampaignLevel()` 初始化空数组，在通关时 `_tryMove()` push 当前关卡数据
- 报告渲染为 DOM 表格，挂载在 `win-modal` 下方，通过 CSS 控制展开
- 星级规则：平均效率 ≥80% → 3星，≥60% → 2星，其余 1星

## 2. 历史记录与进度跟踪

### 2.1 数据模型

新增 localStorage key `mz-history`，存储数组：

```json
[
  {
    "id": "h_1623456789",
    "date": "2026-07-02",
    "mode": "torch",
    "diff": "hard",
    "time": 84,
    "steps": 256,
    "score": 4850,
    "efficiency": 0.72,
    "wallBumps": 3,
    "backtracks": 2,
    "seed": 123456,
    "isCampaign": false
  }
]
```

最多保留 200 条，超出则删除最早记录。

### 2.2 历史记录查看页面

新建历史页面入口，替代/扩展现有底部排行榜区域：

#### 2.2.1 筛选栏

- 模式筛选（全部/标准/火炬/寻宝/黑灯）
- 难度筛选（全部/极简/普通/困难/地狱）
- 排序方式（日期降序/得分降序/时间升序）

#### 2.2.2 记录列表

- 每条显示：日期、模式图标、难度、用时、步数、得分
- 点击展开详情（含效率、撞墙、回溯、种子）

#### 2.2.3 进度图表

三种图表，使用 Canvas 绘制（零依赖）：

| 图表 | 说明 | X轴 | Y轴 |
|------|------|-----|-----|
| 得分趋势 | 各局得分变化 | 日期 | 得分 |
| 用时趋势 | 各局用时变化（低=好） | 日期 | 用时(秒) |
| 效率趋势 | 各局效率变化 | 日期 | 效率% |

- 默认显示当前选中模式+难度的数据
- 图表可切换筛选
- 图表底部显示统计摘要（最高/最低/平均）

### 2.3 数据收集时机

- 每次通关时（`_tryMove` 内 win 分支）push 一条记录到 `mz-history`
- 闯关模式在每关通关时记录，但不重复记录在独立历史中（避免重复）

### 2.4 技术方案

- `Score` 类新增 `addHistory()`, `getHistory()`, `getHistoryStats(filter)` 方法
- 图表用 Canvas 手写绘制，不引入第三方库
- 在设置面板新增"历史记录"卡片，点击打开全屏覆盖层
